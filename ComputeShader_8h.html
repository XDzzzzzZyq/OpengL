Detailed Description

Compute shader implementation for GPGPU operations and post-processing.

ComputeShader manages OpenGL compute shaders for GPU-accelerated parallel computation. Used extensively in the rendering pipeline for post-processing effects (SSAO, SSR, FXAA), shadow generation, and other GPGPU tasks. Supports caching and default parameter configs.

GPU Resource Ownership:

  • Owns compute shader object
  • Owns linked shader program
  • Resources released via glDeleteShader/glDeleteProgram in destructor

Architecture:

  • Global shader cache (comp_list) for reuse across renderer
  • Config cache (config_list) for storing default uniform values
  • Runtime dispatch with configurable workgroup sizes
