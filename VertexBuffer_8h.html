Detailed Description

OpenGL vertex buffer object (VBO) abstraction.

VertexBuffer provides a RAII wrapper around an OpenGL VBO for storing vertex attribute data (positions, normals, UVs, etc.). Inherits copy, move, and deep-copy semantics from GLBuffer.

Note
All OpenGL resources are released deterministically in the destructor.
