Detailed Description

Light source objects for PBR lighting.

Provides the Light class (point, sun, spot, area lights). All GPU buffer management, shadow map rendering, and shadow computation are handled by ShadowSystem (src/render/ShadowSystem.h).

Architecture:

  • Light inherits ObjectID (scene identity) and Transform3D (spatial placement)
  • ShadowSystem converts scene lights into GPU-friendly buffers
  • ShadowSystem owns all shadow map rendering resources and projection matrices
