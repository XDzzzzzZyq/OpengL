Detailed Description

OpenGL uniform buffer object (UBO) abstraction.

UniformBuffer provides a RAII wrapper around an OpenGL UBO for efficient sharing of uniform data across multiple shaders. Inherits copy, move, and deep-copy semantics from GLBuffer. Supports template-based updates for type-safe data transfer.

Note
All OpenGL resources are released deterministically in the destructor.
