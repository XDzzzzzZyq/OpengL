Detailed Description

Type-safe event system for decoupled communication across layers.

The EventPool enables publish-subscribe pattern with compile-time type safety. Components emit events without knowing subscribers, preventing direct coupling.

Architecture:

  • UI emits user actions as events
  • Editor subscribes to events and mutates state
  • Renderer subscribes to config changes
  • No layer directly calls into another layer
