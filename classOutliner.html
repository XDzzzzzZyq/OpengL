void Outliner::RenderLayer ( const Context &  ctx,
const EventPool &  evt 
)
overridevirtual

Renders the layer's UI elements.

Override this to implement layer-specific rendering logic. Called every frame when layer is active and visible.

Typical implementation:

  1. Begin ImGui window with layer name
  2. Render items and custom UI
  3. Handle user input
  4. Emit events for state changes
  5. End ImGui window
Parameters
ctxContext for read-only access to scene/editor state
evtEventPool for emitting events
Note
Must not mutate Context - emit Events instead

Reimplemented from ImguiLayer.
