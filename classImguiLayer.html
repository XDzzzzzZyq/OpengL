Detailed Description

Base class for all UI panels (dockable ImGui windows).

ImguiLayer represents a single UI panel that can be docked, resized, and independently activated. Derived classes implement specific functionality:

  • Viewport: Displays rendered scene
  • Outliner: Shows scene hierarchy
  • TransformPanel: Edits object transforms
  • MaterialViewer: Manages material properties

Lifecycle:

  1. Construction - Layer created with name
  2. RegisterEvents() - Subscribe to relevant events
  3. RenderLayer() - Called each frame when active
  4. Destruction - Cleanup resources

Data Flow:

  • Context (read) → Display state in UI
  • User action → Emit Event via EventPool
Note
Thread-safety: Not thread-safe. Must be used from main thread only.
Ownership: ImguiManager owns layers via shared_ptr

const EventPool &  evt 
)
inlinevirtual

Renders the layer's UI elements.

Override this to implement layer-specific rendering logic. Called every frame when layer is active and visible.

Typical implementation:

  1. Begin ImGui window with layer name
  2. Render items and custom UI
  3. Handle user input
  4. Emit events for state changes
  5. End ImGui window
Parameters
ctxContext for read-only access to scene/editor state
evtEventPool for emitting events
Note
Must not mutate Context - emit Events instead

Reimplemented in MaterialViewer, Outliner, ParamControl, RenderConfigViewer, ShaderEditor, TransformPanel, and Viewport.
