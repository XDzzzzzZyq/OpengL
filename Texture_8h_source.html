29/*
30 * How to add a texture:
31 * 1. Assign a (GLuint) slot for the texture (slot 0-14 are currently in use)
32 * 2. Create a function that allocates a TextureRes in TextureLib
33 * 3. Call that function and bind the texture to the slot chosen in the rendering loop
34 * 4. Pass the slot number to the shader
35 */
