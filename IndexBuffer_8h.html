Detailed Description

OpenGL index buffer object (IBO/EBO) abstraction.

IndexBuffer provides a RAII wrapper around an OpenGL element buffer for storing triangle indices. Inherits copy, move, and deep-copy semantics from GLBuffer.

Note
All OpenGL resources are released deterministically in the destructor.
