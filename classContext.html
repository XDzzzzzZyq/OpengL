Detailed Description

Unified context container aggregating all context types.

Context is the single source of truth for queryable application state. It is passed across layers to enable decoupled data access:

  • Editor mutates Context
  • Renderer receives const Context& (read-only)
  • UI reads Context for display
Note
Architecture: Context enforces one-way data flow and prevents hidden coupling
