Detailed Description

Type-safe event dispatcher using template-based publish-subscribe.

EventPool allows any component to subscribe to events of a specific type and emit events to all registered handlers. Type safety is enforced at compile time via templates, while runtime dispatch uses std::type_index.

Usage:

EventPool pool;
// Subscribe to an event type
pool.subscribe<MyEvent>([](const MyEvent& e) {
// Handle event
});
// Emit an event
pool.emit(MyEvent{param1, param2});

Emits an event to all subscribed handlers.

Invokes all handlers registered for the Event type. Handlers are called synchronously in subscription order. If no handlers are registered, this is a no-op.
